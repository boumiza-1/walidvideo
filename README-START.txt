WALID VIDEO STUDIO — V1 (Remotion)
================================
Première maquette animée de 40 secondes pour Walid Voyages.
Résolution du projet : 1080x1920, 30fps. Composition : WalidSiteAd40.

IMPORTANT : les écrans site-home.png et site-results.png sont des DEMOS
explicitement identifiées. Pour une vidéo publicitaire réelle, remplacez
ces deux fichiers par des captures réelles de www.walid-voyages.com.
Aucun prix n'a été inventé ; aucun vrai paiement n'a été effectué.
Le vrai logo doit être fourni et ajouté avant publication.
La musique et la voix off ne sont pas incluses. Texte dans VOICEOVER_TN.txt.

INSTALLATION sur Windows (PowerShell), après décompression :
1) cd "CHEMIN_VERS\Walid_Video_Studio_V1"
2) npm.cmd install
3) npm.cmd run dev
4) Dans Remotion Studio, ouvrir la composition WalidSiteAd40.

RENDU FINAL :
    npm.cmd run render
Vidéo produite : out\walid-site-40s.mp4

IMPORTANT POUR LE PROJET EXISTANT :
Ceci est un projet Remotion autonome pour éviter d'écraser votre projet
walid-video-studio. Vous pouvez ensuite transférer src/video.tsx et
les deux fichiers public/assets vers ce projet existant si souhaité.

DIFFUSION : vérifiez www.walid-voyages.com, les promotions, la disponibilité
du paiement en ligne et les horaires réels de support avant publication.
